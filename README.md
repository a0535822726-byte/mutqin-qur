# ديني | Deeni

مشروع تطبيق أندرويد عربي باسم ديني.

## الميزات الحالية
- مصحف كامل يُحمّل نصه العثماني أثناء البناء مع فحص عدد السور والآيات.
- البحث عن السور وتحديد نطاق الآيات ومتابعة آخر قراءة.
- إخفاء الآيات للتدرب على الحفظ.
- جلسة تسجيل تلاوة من الميكروفون مع مؤشر مستوى الصوت وحفظ التسجيل والاستماع إليه.
- أذكار مختارة ومسبحة تحفظ عدد التسبيحات محلياً.
- واجهة عربية RTL ووضع ليلي.

## ملاحظة مهمة
التصحيح الآلي للكلمات وأحكام التجويد غير مفعّل بعد؛ التطبيق لا يصدر درجات وهمية. هذه الوظيفة تحتاج دمج محرك تعرف قرآني متخصص والتحقق من دقته.

## ملف APK
يبدأ GitHub Actions بالبناء تلقائياً بعد تحديث الملفات، ثم ينشر APK في إصدار GitHub باسم ديني إذا نجح البناء.
