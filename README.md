# مُتقن | Mutqin — المنصة القرآنية والإسلامية الموحدة

**القرار:** متقن هو التطبيق الرئيسي الوحيد. ندمج فيه أفكار تجربة التسميع والحفظ الذكي الشبيهة بترتيل، وجميع أقسام ديني، بتنفيذ مستقل وهوية متقن، دون نسخ كود أو شعار أو واجهات أو محتوى محمي من تطبيق آخر.

> الأعداد التالية أهداف المستخدم للمكتبة النهائية وليست محتوى منجزًا حاليًا. لا تعرض الواجهة الأهداف كأنها مواد موجودة.

## تجربة القرآن والتسميع (مستوحاة وظيفيًا لا منسوخة)
- مصحف بالسور والأجزاء والصفحات، البحث، آخر موضع، المفضلة والعلامات.
- تسميع من الحفظ: اختيار السورة والآيات، إخفاء النص، تسجيل التلاوة والاستماع إليها وتكرار المقاطع.
- الاستماع لقارئ: اختيار القارئ، تشغيل الآيات، التكرار، سرعة التشغيل والتنقل (يتطلب مشغلًا ومصادر صوت مرخصة).
- مراجعة واختبارات وخطط حفظ وتتبع التقدم.
- تصحيح التلاوة لا يُفعّل إلا بعد دمج نموذج صوتي قرآني متخصص واختباره. يجب فصل أخطاء النص عن أحكام التجويد والمخارج والصفات. لا تُعرض درجات أو تصحيحات من مجرد تسجيل الميكروفون أو تحويل الكلام إلى نص.
- لا تمييز للكلمات المتعثرة إلا بمحاذاة صوتية دقيقة متحققة.

كل درس تجويد يشمل الحكم والتعريف والسبب والموضع والمثال وطريقة الأداء والأخطاء والتمرين والاختبار. وكل حديث يشمل النص والراوي والمصدر والتخريج والدرجة والشرح. وكل مسألة فقهية تشمل السؤال والحكم والدليل والشرح والخلاف المعتبر والمراجع. وكل قصة لها أدلة ومراجع مع بيان الروايات المختلف فيها.

## هيكل التطبيق الموحد
1. **الرئيسية:** متابعة اليوم، آخر موضع، هدف الحفظ، جلسة تسميع سريعة، الصلاة والانتقال للأقسام.
2. **القرآن:** المصحف، البحث، التفسير، المفضلة، التنزيلات والقارئ.
3. **التسميع:** تسميع من الحفظ، الاستماع، التسجيل، المراجعة والاختبار.
4. **التعلم:** التجويد، التفسير، الحديث، الفقه، السيرة، القصص والاختبارات.
5. **العبادات:** الأذكار، الأدعية، المسبحة، الصلاة والقبلة.
6. **إنجازي:** خطط الحفظ والمراجعة والإحصاءات وسجل الجلسات.
7. **الإعدادات:** المظهر والخط والصوت والتنبيهات والخصوصية وإدارة البيانات.

## سياسة المصادر والدقة
- القرآن: يمكن استخدام نص تنزيل (Tanzil) حرفيًا مع إبقاء إشعار الحقوق ورابط المصدر، ولا يجوز تغيير النص. راجع https://tanzil.net/docs/Text_License قبل التوزيع.
- الحديث: واجهة Sunnah.com الرسمية توفر جزءًا من البيانات وتتطلب مفتاح API، وتُراجع البيانات يدويًا على مراحل؛ لا تُسحب بياناتها بالجملة دون إذن. راجع https://sunnah.com/developers.
- التفسير: يمكن تقييم Quranpedia API كمصدر حي للتفاسير، مع مراجعة شروط كل مادة ومصدرها قبل التخزين أو إعادة النشر: https://api.quranpedia.net/v1.
- الحديث مع المصدر والتخريج والدرجة كما يذكرها مرجع موثوق؛ لا اختلاق أرقام أو أحكام.
- القصص من القرآن والأحاديث المقبولة ومراجع السيرة والتراجم، مع تمييز الروايات المختلف فيها.
- الفقه يوثق الدليل وينسب الأقوال ويظهر الخلاف المعتبر، ولا يكون التطبيق بديلًا عن أهل العلم.
- التجويد يراجع علميًا، مع التنبيه إلى أن إتقان الأداء يحتاج سماعًا من معلّم مؤهل.
- لا نسخ كامل لكتب أو قواعد بيانات محمية دون إذن؛ يستخدم المحتوى المرخص أو الملخص بصياغة أصلية مع الإحالة.
- لكل مادة سجل مصدر ومرجع وحالة تحقق ومراجع وتاريخ مراجعة. غير المتحقق لا ينشر.

## الحالة الفعلية الحالية
- أضيفت أول 20 درس تجويد منظمة: الهدف والتعريف والقاعدة والأمثلة والتدريب والأخطاء الشائعة والمرجع. هذا تقدم أولي في المكتبة وليس إكمال هدف 300 درس.
- بقية أقسام المحتوى ما زالت تحتاج إدخال المواد الفعلية ومراجعة مصادرها؛ الأهداف لا تعني أن المواد موجودة.
- واجهة أندرويد عربية RTL ومظهر فاتح/داكن.
- قراءة نص القرآن حسب السورة والآيات واختيار نطاق.
- إخفاء الآيات للتدرب على الحفظ.
- تسجيل التلاوة محليًا والاستماع للتسجيل.
- أذكار مختارة ومسبحة تحفظ العداد.
- أضيف حفظ مواضع الآيات المفضلة؛ يلزم التحقق من نجاح البناء النهائي.
- لا يوجد بعد مصحف المدينة المصور بصفحات 604 داخل القارئ.
- لا يوجد بعد مشغل قراء متكامل أو تصحيح ذكاء اصطناعي موثوق للتجويد.
- لا توجد بعد مكتبات المحتوى بالأعداد المستهدفة أعلاه.

## مراحل الدمج
A. توحيد التنقل والهوية والتخزين، ثم المصحف والعلامات والموضع الأخير والمفضلة.
B. تحسين جلسات التسميع والتشغيل والتكرار، ثم مشغل القارئ؛ بعدها فقط يُختبر دمج محرك تقييم صوتي متخصص.
C. إضافة مكتبات التجويد والتفسير والحديث والفقه والقصص والسيرة والأذكار بمصادر وتحقق.
D. مواقيت الصلاة والقبلة والخطط والتنبيهات والإحصاءات والنسخ الاحتياطي.
E. اختبارات شاملة، مراجعة شرعية، اختبار Android 15 وفحص APK قبل النشر.
