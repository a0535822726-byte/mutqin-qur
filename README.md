# مُتقن | Mutqin

تطبيق أندرويد عربي للقرآن والذكر.

## الميزات الحالية
- المصحف والبحث عن السور وقراءة الآيات واستئناف آخر موضع.
- إخفاء الآيات للتدرب على الحفظ.
- تسجيل التلاوة والاستماع إلى التسجيل.
- الأذكار المختارة.
- مسبحة إلكترونية تحفظ العداد.
- واجهة عربية ووضع ليلي.

## ملاحظة
التصحيح الآلي للكلمات وأحكام التجويد غير مفعّلة حالياً، ولا يعرض التطبيق نتائج أو درجات غير موثوقة.

يتم بناء ملف APK عبر GitHub Actions عند تحديث المشروع.
